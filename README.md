# spacetimeki.github.io

My personal portfolio site featuring a terminal-style interface. Built to showcase my coding skills and highlight projects I've worked on.

**Live site:** https://spacetimeki.github.io

## What is this?

This is a simple, retro-style website that demonstrates my ability to build clean, interactive web interfaces. It's inspired by the Arch Linux terminal - type `help` to see available commands, or just click around and explore.

The `projects` command opens a separate blog where I document my work in more detail.

## Tech stack

- Plain HTML/CSS/JavaScript for the main site
- React + Vite for the blog subproject
- GitHub Actions for deployment
